# Assets

Non-code assets for the course.

| File | Purpose |
|---|---|
| [models/shopdb-model.mwb](models/shopdb-model.mwb) | MySQL Workbench ER model of the `shopdb` schema — open it in Workbench to see the tables and relationships graphically |

The modules' own diagrams live beside them, as Mermaid blocks in each module's `assets/` folder
(`modules/NN-slug/assets/<slug>.md`). The schema these assets describe is documented in
[docs/DATASETS.md](../docs/DATASETS.md).
