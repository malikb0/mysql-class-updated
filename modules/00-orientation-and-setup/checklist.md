# Module 00 — Orientation & Setup · Checklist

Tick each box once you can do it **without looking**. If you get stuck, re-run the matching command
in [`notes.md`](notes.md).

- [ ] Explain, in one sentence, what a relational database is.
- [ ] Start MySQL with `make up` and confirm the container is running.
- [ ] List the tables in `shopdb` with `SHOW TABLES;`.
- [ ] Describe a table with `DESCRIBE persons;` and read one column's type.
- [ ] Count rows with `SELECT COUNT(*) FROM ...;`.
- [ ] Return and sort a few rows with `SELECT ... ORDER BY ... LIMIT ...;`.
- [ ] Say what a **primary key** is and name the primary key of `persons`.
- [ ] Fix a "can't connect" error using the common-errors table in `notes.md`.

When every box is ticked, you are ready for **Module 01 — Creating Tables (DDL)**.
